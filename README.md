# Music Persona
음향 특성으로 탐색하는 나의 음악 취향 지도. PCA·UMAP, 선택곡 유형 요약, 유사곡 비교, PNG 저장.

## 실행
Node.js 22 이상. `npm ci`, `npm run build`, `npm run dev` 후 http://localhost:5173 접속.

## 데이터 및 분석
120곡 모두 가상 곡이며 5개 음향 특성은 고정 seed의 합성 데이터입니다. Spotify 데이터나 실제 음원이 아닙니다. 실제 데이터 적용에는 분석·배포 권한 검토가 필요합니다.

전체 기준 데이터의 각 특성을 평균 0, 표준편차 1로 표준화하고 ml-pca로 PCA를 계산합니다. UMAP은 umap-js, nNeighbors=12, minDist=0.18, nEpochs=250, seed=42를 사용합니다. 선택을 바꿔도 기준 지도는 고정됩니다. 유사곡은 원래 5차원 표준화 특성의 유클리드 거리로 구합니다. UMAP 축과 전역 거리·군집 크기에 직접적인 의미를 부여하지 마세요. 키는 현재 분석에서 제외했습니다.

유형은 선택곡의 평균 에너지, 댄서빌리티, 어쿠스틱 특성에 대한 규칙 기반 요약입니다. 성격 검사 또는 검증된 심리 유형이 아닙니다.
